# Наша история

Романтический сайт-подарок для Самишки.

## Запуск

1. Откройте проект в браузере через локальный сервер:
   - `python3 -m http.server 8000`
2. Перейдите по адресу: http://localhost:8000

## Где хранить фотографии и видео

- Фотографии: `media/1.jpg`, `media/2.jpg`, `media/3.jpg`, `media/4.jpg`, `media/5.jpg`, `media/6.jpg`
- Музыка: `media/track.m4a`

## Что подготовлено заранее

- В папке media уже лежат фото `1.jpg`...`6.jpg` и трек `track.m4a`.
- Если файл музыки заменить на другой `.m4a`, сайт автоматически использует его.
- Если файл не найден, сайт включает мягкий синтезатор-заглушку, чтобы музыка не прерывалась.

## Как заменить контент

- Для фото: замените `media/1.jpg`...`media/6.jpg` на свои реальные снимки.
- Для музыки: замените `media/track.m4a` на свой трек в том же формате.
- Для текста: отредактируйте блоки в `index.html` или массивы в `script.js`.
